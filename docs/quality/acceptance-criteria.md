# Acceptance Criteria

完成と判断するための最低基準です。

## Required

- [ ] 実際に切り出せる構成になっている
- [ ] 折り線が判別できる
- [ ] のりしろがある
- [ ] 側面図と上面図の全長が一致する
- [ ] 前面・背面・上面の全幅が一致する
- [ ] 前面・背面・側面の全高が一致する
- [ ] 左右側面のホイール中心が一致する
- [ ] 主要な車体位置が各方向で矛盾していない
- [ ] 車種の主要特徴が残っている
- [ ] 印刷時に線やパーツが欠けない

## Preferred

- [ ] A4 1枚に収まる
- [ ] 余白とパーツ間隔が十分
- [ ] 小部品が過度に複雑でない
- [ ] 家庭用プリンターで見やすい
- [ ] パーツ名や接続関係が必要に応じて分かる

Requiredを満たしていない場合、見た目が良くても完成扱いにしません。
