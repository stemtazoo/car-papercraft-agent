# Review Output

生成結果は見た目ではなく、次の順番で確認します。

## 1. Buildability

- 面同士が接続できるか
- のりしろがあるか
- 折り線と切り取り線が区別できるか
- 組み立て時に明らかな干渉がないか

## 2. Dimensions

- 側面と上面の全長
- 前後面と上面の全幅
- 前後面と側面の全高
- 左右側面のホイール位置

を確認します。

## 3. Landmarks

- ドア
- 窓
- ピラー
- フェンダー
- ライト
- バンパー

が方向図間で矛盾していないか確認します。

## 4. Vehicle identity

参考画像の主要な特徴が残っているか確認します。

ただし細部の不足より、寸法不整合を先に修正します。

## 5. Print layout

- A4内に収まる
- 線が欠けない
- パーツが重ならない
- 切りやすい余白がある

ことを確認します。

## Review result

評価結果は、少なくとも

- pass
- revise
- uncertain

のどれかに分け、理由を短く残します。
