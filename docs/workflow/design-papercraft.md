# Design Papercraft

## 1. Start from shared geometry

最初に共通寸法と主要位置を決めます。

方向図ごとに独立して描き始めないでください。

## 2. Decide body segmentation

車体を、紙で折って作れる面へ分けます。

例:

- roof
- hood
- trunk
- left side
- right side
- front
- rear

複雑な曲面は、必要に応じて複数の平面へ近似します。

## 3. Define connections

どの面とどの面を接続するか決めます。

接続部には、

- fold line
- glue tab
- matching edge

が必要です。

## 4. Add tabs

のりしろは、

- 小さすぎて貼れない
- 隣のパーツへ重なる
- 折り線を妨げる

状態を避けます。

## 5. Add optional parts only when useful

必要に応じて、

- タイヤ
- ミラー
- バンパー
- マフラー
- ナンバープレート
- タクシーサイン

を追加します。

小部品を増やすこと自体を品質と考えないでください。

## 6. Layout on A4

基本はA4 1枚を目標とします。

- 車体本体を優先
- 余白を確保
- 切り取り線を欠けさせない
- 必要に応じて横向き
- 長い車でも寸法比率を崩さない

A4 1枚へ無理に詰めることで工作性が大きく落ちる場合は、1枚完結を上位条件より優先しないでください。
