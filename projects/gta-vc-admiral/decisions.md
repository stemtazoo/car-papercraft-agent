# Decisions

## Geometry

初期共通ジオメトリは ratio-first で管理する。

| parameter | ratio |
|---|---:|
| length | 1.00 |
| width | 0.39 |
| height | 0.31 |
| wheelbase | 0.59 |
| front overhang | 0.21 |
| rear overhang | 0.20 |

A4試作時の暫定完成全長を 165 mm とした場合の目安:

- 全長 165 mm
- 全幅 約64 mm
- 全高 約51 mm
- ホイールベース 約97 mm
- 前オーバーハング 約35 mm
- 後オーバーハング 約33 mm

これらは実車寸法ではなく、参考画像から作るペーパークラフト用の初期設計値。

## Color

- 基本車体色は白
- 窓は濃いグレー〜黒
- 側面モール、バンパー、窓枠、Bピラーは黒系
- グリルは濃いグレー〜黒、縦桟を明確にする
- ライト類は印刷表現
- ホイールはグレー系

## Simplifications

基本構成:
1. left side
2. right side
3. hood + windshield + roof + rear window + trunk を連続した上面ストリップ
4. front fascia
5. rear fascia
6. underbody / floor
7. wheels

初回は以下を印刷表現とする。

- ヘッドライト
- グリル
- テールランプ
- ナンバープレート
- 側面モール
- ドア境界
- ドアハンドル
- 窓枠

ミラーは別部品にせず、省略または印刷表現を優先する。

## Layout

A4横向きを第一候補とする。

- 左右側面を同一長さで配置
- 上面ストリップの全長を側面と一致させる
- front/rear fascia の幅を上面最大幅と一致させる
- floor は残り領域へ配置
- wheels は小パーツ領域へまとめる
- のりしろは上面ストリップ側を中心に付ける
- 白い車体パーツは切断線が見えにくくならないよう、輪郭線を十分な濃さで出す

初回は工作性を優先し、車体本体のパーツ数を増やしすぎない。
